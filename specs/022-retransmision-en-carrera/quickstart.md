# Quickstart 022

1. `npm run build && npm run harness` — sin regresiones (mismos checks).
2. Preview + entrar en un GP: tarjeta de presentación (nombre, vueltas,
   silueta) → un toque y arrancan las luces; sin tocar, sola a ~2,5 s.
3. En carrera: deltas ▲/▼ en la torre (salida = 0, nadie marca);
   tras adelantamientos se mueven. A 390 px la fila sigue completa.
4. Termina la carrera (20x va rápido): podio + "mis coches" en grande +
   lista/dinero/acciones de siempre. Prueba también una carrera con
   muchos DNF (el podio se adapta).
5. Móvil: podio legible y acción principal al pulgar.
