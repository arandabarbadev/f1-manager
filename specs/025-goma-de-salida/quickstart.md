# Quickstart: 025 Goma de salida

## Cómo verlo

1. `npm run build && npm run harness` (verde, con "Goma check").
2. Preview 4173 + Chrome CDP 9222; guion `%TEMP%\mm-v025.js`.
3. A mano: entra en una carrera (o sprint), tras la tarjeta del GP
   elige S para un coche y H para el otro, pulsa Salida y mira la torre.

## Qué mirar

- La tarjeta sale SOLO en carrera/sprint (quali no).
- Sin tocar gomas: un toque en Salida y arranca (preselección).
- Torre: la goma elegida en cada uno de mis coches desde el segundo 1.
- Reloj a 0:00 mientras la tarjeta está abierta.
- Móvil 390 px: botones de goma ≥44 px, todo a pulgar.
