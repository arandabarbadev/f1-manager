# Quickstart: 029 Rivales evolucionan

## Cómo verlo

1. `npm run build && npm run harness` (verde, con "Rivales check").
2. Preview 4173 + Chrome CDP 9222; guion `%TEMP%\mm-v029.js` (siembra
   una temporada completa y abre su resumen).
3. A mano: termina una temporada (o siémbrala) y abre el resumen: el
   bloque "Los rivales no se duermen" enseña el top 3; tras "Empezar
   temporada nueva", Rivales tiene mejores stats.
